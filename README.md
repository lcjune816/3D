##**Player**
- 게임의 주요 상호작용은 플레이어의 손, 팔을 통하여 이루어 지도록 구현 했습니다. 오브젝트의 판정은 ray로 탐색하여 가까운 거리에 있는
  오브젝트와 상호작용하게 구현 하였습니다. 팔이 늘어나는 연출 시작, 끝점 기준으로 보간한 위치에 매쉬를 배치하는 형태로 구현 하였습니다.

##**Map Object**
- 맵 오브젝트 전체의 배치가 끝났을때는 첫번째 맵 대략 1천 5백개의 오브젝트 두번째 맵은 대략 2천개의 오브젝트가 설치가 되었으며,
  리소스 로딩 랜더링에 대한 최적화가 필요 하였습니다.
  
###**Resoruce Caching**
 - 초기에 오브젝트가 만들어질때마다 매쉬, 텍스쳐를 새로 로드하는 형태로 하였으나 동일한 리소스가 메모리에 반복해서 올라가는 문제가
  있었습니다.
  이를 개선하기 위해, 초기 로드시에만 리소스를 컨테이너에 저장하고, 동일한 리소스를 사용할 경우 해당 리소스의 인덱스 참조하도록 변경 하였습니다.
###**Resource Binary**
  - 초기 Mesh 데이터는 Assimp를 통해 FBX 파일에서 직접 로드를 하였습니다.
  - 이 경우 실제 랜더링에 필요없는 데이터도 같이 로드하고 있어 시간이 메모리 점유율이 증가했습니다.
  - 이를 개선하기 위해 데이터(Vertex, Index, Material 등)만 Binary화 하였습니다.
  - Binary 파일이 존재할 경우 해당 데이터를 바로 로드 그렇지 않을 경우 FBX를 Assimp로 로드한 뒤 Binary화 하는 형태로 구성 했습니다.

###**Instancing**
- 오브젝트들을 개별적으로 랜더링 하다보니 DrawCall이 많아 부하가 있었습니다. 부하를 줄이기 위해 동일한 매쉬 텍스쳐를 사용하는 정적 오브젝트들의 Transform을 하나로 묶어서 하나의 DrawCall로 여러 오브젝트를 렌더링 하도록 최적화 했습니다.

##**Interaction Object**
- 오브젝트 간의 서로 상호작용이 필요하여 오브젝트간에 전체 순회 비용을 줄이기 위해,
  TriggerManager를 만들어 상호작용이 필요한 오브젝트들을 담아 서로간에 참조가 바로 가능하도록 인덱스 번호를 부여하는 형태로 진행 하였다.

상호작용을 위한 주요 오브젝트들은 Battery, Battery Case, Electronic Panel, Electronic Pole 등이 있습니다.
###**Battery**
  - 플레이어의 손과 충돌시 손의 위치를 따라가도록 구현했습니다.
  
###**Battery Case** 
  - 배터리와 상호작용시 배터리는 케이스의 지정된 위치로 이동하, 배터리 케이스와 연결된 Electronic Panel이 활성화 되도록 구현했습니다.
  
###**Electronic Panel**
  - 전기 패널은 활성화 / 비활성화 상태를 가지며 활성화되어있는 패널은 플레이어의 손과 상호작용시 플레이어의 손과 팔에 전기 이펙트를
  활성화 함으로 비활성화 된 전기 패널과의 상호작응을 하여 그 전기 패널과 연결된 문, 발전기를 활성화 할 수 있도로 구현했습니다.
  
###**Electronic Pole**
  - 플레이어의 팔에 전기가 활성화된 상태에서 닿으면 Electronic Pole에 조명이 켜지며 활성화 되었다는 상태로 변경됩니다.
  기둥이 닿은 판정은 시작점에서 끝점으로 Ray로 판정 했습니다.
  - 팔 시작점 -> 전기 기둥이 닿은 위치를 담고 마지막으로 닿은 위치로부터 다시 플레이어의 시작점으로 Ray를 쏘아서 추가적으로 팔에 닿은 부분이 있는지 판정을 하였고 만약 팔에 닿은 지점이 추가적으로 생기면 오브젝트에 팔이 감기는 형태로 구현을 하였습니다.
  - 팔을 플레이어 이동으로 감거나 풀때는 마지막 지점으로부터 Normal Vector를 미리 구해놓고 외적으로 내부/외부 인지 판정을하여 다시 감거나 풀 수 있게 구현했습니다.

##**Boss**
  - 플레아어와 마주보고 있을때만 멈추고 그 외에는 플레이어를 추적하는 형태입니다.
  - 현재 바라보는 방향과 플레이어의 바라보는 방향을 내적하여 멈출지 이동할지를 결정하도록 구현 했습니다.
  - 플레이어를 추적할때는 설치해놓은 네비매시에 Astar 알고리즘 길찾기를 적용하여 추적할 수 있도록 했습니다.
